How to Sign Your APK

Open your Windows Command Prompt (cmd) and run the following absolute path command to sign your package using the utility tool:

java -jar "D:\LABORATORY\Packages\.windows\.Utilities\uber-apk-signer\uber-apk-signer-1.3.0.jar" --apks "path\to\your\app.apk"

Note: Remember to replace path\to\your\app.apk with the actual location of the APK file you intend to sign.
