Installing VM using Virtual Master

Disclaimer: This is just an HTML file you downloaded into your phone. You can check the contents by converting to text, it's just meant to help my friends. 😊
Requirements: Above 4 GB RAM, About 3-4 GB space free, A spare G-Mail ID meant only for experiments, Data cost ~ 1.8 GB

Installing VM

  1. Install AVM
  2. Enable Developer Options:
    3. Open settings app ▶️ Scroll down to About Phone ▶️ Software Information ▶️ Click Build Number 7 times ▶️ Allow Developer Mode.
  3. Memory = Smoothness of running VM:
    4. Open settings app ▶️ Scroll down to Developer Mode ▶️ Note your RAM (Memory): Larger memory = Lower lagging = More apps can be run simultaneously (Best if > 4 GB total, since VM's take up huge Memory).
  4. DCPR:
    5. Inside Developer Options page ▶️ Scroll much down to Disable child process restrictions ▶️ Enable the option.
  5. Battery:
    6. Settings ▶️ Search and open Optimise Battery Usage ▶️ Set Filter to All ▶️ Scroll down to Virtual Master ▶️ Toggle off.
  6. Install ROM:
    7. Open AVM ▶️ Create VM ▶️ Select and Download ROM 9.0.0 64 bit (about 400 MB) In-App ▶️ After download, select that ROM ▶️ Next ▶️ Resolution: Default Portrait ▶️ Name and Complete

Initialize VM

  1. Spare G-Mail Account:
  2. Create a spare Google account, optionally make it "un-suspicious" by giving it genuine-looking details such as age 22, a common name, etc. Nationality may be kept same, because IP address should point to same location.
  3. AVM ▶️ Launch the VM: First time Boot ▶️
  4. Enable Google Services:
    5. Inside VM ▶️ App Screen ▶️ VM Settings ▶️ (Topmost) Enable Google ▶️ VM should restart.
  5. Install Play Games:
    6. After Restart, inside VM ▶️ App Screen ▶️ New app Play Store, open ▶️ Login using spare Google account ▶️ Search and check if Google Play Services is updating / updated to latest version ▶️ After it's updated, install Play Games.
  6. Login to Play Games using the spare account ▶️ Create a brand new Play Games account.

Game Modding

  1. Add game to VM: ℹℹℹ
    2. AVM ▶️ App Screen ▶️ Add Apps ▶️ Import Among Us (AU in host phone should be updated to latest version, as described Here in Play Store.
  2. Register new Among Us account:
    3. Open Among Us, register the new spare G-Mail account into Innersloth, give an age above 18, and check that the account is successfully created.
  3. Download PP:The following is not a download link. It redirects you to the shared folder. Therein download the PP apk from 3-dot menu of the apk file.
    4. Polar Patcher APK
  4. Play Store ▶️ Profile / Settings ▶️ Play Protect ▶️ Turn it off completely.
  5. Install PP:
    6. AVM ▶️ Add Files ▶️ Browse to the path "Internal Storage/Download/Polar Patcher_v1.0.apk" ▶️ Select and import it ▶️ It will be auto-installed after being downloaded into the VM.
  6. Finished. Start using PP following its own instructions.

Add-Ons ℹℹℹ

If you feel like you want another layer of mods, then delete the official Among Us app that you imported into your VM, and instead download and install Unsigned APK from either aadilmods.com or platinmods.com and use that as the base app on which PP will hook to during runtime. Unlike PP, their mods are menus that are by default part of game itself.. Unsigned apks do not automatically install on any OS, while signed apks won't let you login the second the time in Aadil Mod or even the first time in Axey (Platinmod) Mod. Compare latest version features of both mods and download the APK as per your need. Here are the two pages as of June. It is recommended that you install all these directly inside the VM, but do not install in personal phone.. Also it is recommended to first install the next two files: Magisk and PMPatchFull, because seeing an apk being downloaded the VM will try to auto install but throw errors in absence of signature.
Platinmods Page Aadilmods page

(Note: Some pages may throw unnecessary redirects and may not install at all, in that case you already have Magisk and PmPatchFull below... So try to ask someone for unsigned Aadil apk. For Platinmod, you need to make an account (use spare G-Mail) on their website, and like the post to unveil the download link.)


For both, you need to install Magisk into the VM to root it (it will restart) and then a module called PMPatch that disables signature verification for that Android (because above mods are unsigned). Do not by mistake install (download is fine) Magisk into personal phone. First get both the following files into your VM. (In the default file manager you can view Internal Storage using the menu option on top.)
Magisk_vXX.x.apk PMPatchFull.zip
Install Magisk INSIDE VM (not in personal profile) ▶️ Restarts ▶️ from Play Store, Install Root Checker inside VM ▶️ Open it ▶️ Instantly allow it Root Access in the popup that comes for 8 seconds ▶️ It should say Root is successful.
In Magisk ▶️ Home ▶️ Settings (top right) ▶️ Enable Zygisk ▶️ Back to Home ▶️ Under Magisk Header, it should say Installed (and a string), Zygisk Yes, Ramdisk Yes. ▶️ Go to Modules Tab ▶️ Activate PMPatchFull Module by browsing to that .zip file.
Finally navigate to the mod apk file, install it normally using Package Installer.
Now open the app, login optionally (or mandatorily in case you haven't registered yet), to see its mod menu. However, use PP mod menu, and you now have double layered mod.
